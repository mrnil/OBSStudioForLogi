OBS for Logi Icon Set

Every button icon in the OBS Studio plugin for Logitech and Loupedeck consoles, drawn on black keys as the device shows them. The spec below is the reference for new icons. The full rules live in docs/ai/icon-style.md.

Construction

  • CanvasviewBox="0 0 32 32", 32×32. The SDK scales it to the key.
  • Glyph areaInside 4–28px on both axes. No background shapes; code paints the key.
  • Line2px outlines with round caps and joins; corners radius 1–2px.
  • MarkupFilled paths only: no strokes, transforms, masks or clip paths in shipped files. Author with strokes, then flatten with picosvg.
  • Names<Feature><State>[Disabled].svg, named after what the picture shows.
